# Glossary

These are the key terms relevant for adoption process. They should stay consistent around the application.  

| Term         | Description                                                          | Synonyms             | German                           |
|--------------|----------------------------------------------------------------------|----------------------|----------------------------------|
| Adoption     | The process of finding a new owner for an animal                     |                      | Vermittlung; Vermittlungsprozess |
| Organization | The club, non-profit performing the adoption or providing the animal | Club; non-profit; NGO | Organisation; Verein             |
| Person       | Someone Taily manages (mediator, foster, inspector, contact); can have several roles. Applicants are not Persons by default |  | Person                           |
| Member       | Person that is part of this applications organization                |                      | Mitglied                         |
| Mediator     | Person supervising the adoption                                      |                      | Vermittler                       |
| Applicant    | Whoever applied to adopt; their data is stored on the adoption       |                      | Bewerber:in                      |
| Adopter      | The applicant once the mediator works on the adoption                |                      | Adoptant:in                      |
| Foster       | Person providing shelter for an animal until handover                |                      | Pflegestelle                     |
| Inspector    | Person performing an inspection of the adopter                       |                      | Prüfer                           |
| Tasso        | Online service for registering dogs and finding them when missing    |                      |                                  |
| User         | General term for someone using this application.                     |                      | Benutzer                         |
| Case File    | Everything an adoption knows about if and how it can happen          | Adoption data        | Angaben                          |
| Field        | One configurable piece of data in the case file                      | Custom field         | Feld                             |
| Field Group  | Section that structures fields and hints                             |                      | Abschnitt                        |
| Pre-Inspection | Check of the adopter's home before an adoption is finalized        | Inspection (informal) | Vorkontrolle                    |
| Follow-up Inspection | Checkup some time after the handover (planned)               |                      | Nachkontrolle                    |
| Memo         | Inspector's internal notes on a pre-inspection                          |                      | Notiz                            |
| Checklist    | What is still missing for a step                                     |                      | Checkliste                       |
| Applicant Portal | Page where the applicant, logged in by email and magic link, follows their adoptions and edits their data | Portal | Meine Bewerbungen |
| Application link | The public link to an animal's application form, copied from the animal | | Bewerbungslink |
| Magic link   | Single-use emailed link that confirms an application or logs into the portal | Applicant Link | Link per E-Mail |
| Unconfirmed application | A public application whose email isn't confirmed yet | | E-Mail nicht bestätigt |
| Earlier adoptions | The applicant's other adoptions, found by email or a referenced Person | Related adoptions | Frühere Vermittlungen |
| Requirement Override | A mediator's per-adoption change to when a field is required | | Anforderung |
| Audit Trail  | History of who changed what and when                                 | Change history       | Änderungsverlauf                 |
| Contract     | Protection contract signed by adopter and mediator                   |                      | Schutzvertrag                    |
| Contract Template | Configured contract: wording and the fields it prints, offered per animal type | | Vertragsvorlage; Vertrag (settings) |
