# Context Map

## Contexts

- [API](./api/CONTEXT.md) — adoption domain: animals, persons, adoptions, case files, pre-inspections, contracts, the public application and the applicant portal
- [Frontend](./frontend/CONTEXT.md) — UI-specific terms for the admin SPA, the catalogue editor, the token pages and the applicant pages

## Relationships

- **API → Frontend**: The frontend consumes the API's domain concepts directly. Terms defined in the API context are canonical; the frontend context only adds UI-specific vocabulary on top.
